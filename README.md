# Cube Lab：三阶魔方七步法

运行 `node server.js`，打开 <http://127.0.0.1:8787/>。需要 Node.js 18 或更新版本。

层转动使用SpaceJoe的真实魔方转动录音（CC0），已剪裁首尾静音并按90° / 180°动画制作播放片段，保留录音的音高与塑料摩擦、卡位声，不叠加合成噪声。素材保存于 `assets/audio/`，来源与加工说明见 `assets/audio/CREDITS.md`。手动、撤销和Jev操作共用音效。右上角「试听魔方声」可直接试听而不改变状态，「音效：开 / 关」可静音，偏好自动保存在本地。首次点击或按键后解锁浏览器音频，隐藏页面自动静音。不支持Web Audio的浏览器仍可正常操作魔方。实际打乱也同步播放层转动音效；拖动观察视角不播放。请使用本地HTTP服务加载音频；服务启动后，播放不依赖外部素材网站。

1. 点击「AI 设置」，输入 Jev API Key 并保存；设置面板自动收起。
2. 点击「重新打乱」，然后点击「开始底层十字」。
   打乱会逐步播放20次真实层转动及对应录音；随机打乱卡片高亮当前公式，并显示完成进度，左侧记录每次已执行动作。打乱期间锁定其他转动和AI入口，计时保持归零，结束后恢复操作。刷新时保留已实际执行的转动及状态。
3. 第1步完成后自动停止，左侧切换到「2 · 底层一面」。点击「开始底层一面」，继续归位四个底角。已完成十字的状态载入时会直接选择第2步。
4. 左侧显示四个目标块、经过模拟的候选方案、Jev 选择、当前短公式和逐次转动记录。「查看底层」可以观察黄色底面。
5. 第2步完成需要底层十字正确、四个底角位置正确、黄色朝下且两个侧色分别对齐中心；达到条件后自动停止。
6. 点击「停止」可暂停。第1步在当前完整转动后停止；第2步在当前顶层对位或三次转动的取出 / 插入公式完成后停止，使十字和先前完成的底角恢复，之后可从实际状态继续。

本版本支持七步法全部7步，每步完成后单独停止并选中下一步，下一步需点击开始。刷新时选择实际状态中最早未完成的一步；可以通过左侧按钮或设置中的操作目标切换阶段。第7步通过六面检查后显示“整个魔方已复原”。

也可以点击左侧「一键完成七步」：从当前实际状态开始，跳过已完成阶段，连续调用Jev完成剩余步骤，直到六面54/54全部通过检查。过程中显示当前第几步、方案、转动和日志。点击「停止」会取消后续所有阶段，并在当前阶段的安全停止点停下；网络错误、Jev暂停、无效响应或保护检查失败也会中止连续执行。再次点击可从当前状态继续。已复原时不会调用Jev。

单步AI与一键七步在实际开始任务时自动开始或继续计时，包括规划、等待Jev和动画时间；任务完成、停止、暂停或出错时暂停计时。连续七步切换阶段不中断、不清零。再次操作累计已有时间，重新打乱、复原或手动重置计时器时清零。AI运行期间计时器由任务管理，手动暂停、重置及空格切换暂时禁用；仅打开设置或未通过启动条件不会开始计时。

## 第3–5步

| 步骤 | 前提 | 完成条件 |
| --- | --- | --- |
| 3 · 中层棱块 | 完整底层已复原 | FR、RB、BL、LF四个中棱位置和两色朝向全部正确，底层保持完整 |
| 4 · 顶层十字 | 前两层完整 | 四个白色顶棱朝U，前两层保持完整；不要求顶层侧色排列 |
| 5 · 顶面同色 | 前两层及白色顶层十字正确 | 四个顶角白色朝U、顶面九张白色朝上；保留前两层及十字 |

点击「查看顶层」观察白色贴纸方向。第4步显示点 / 折线 / 一字 / 十字形态，第5步显示朝上的白色顶角数。完整公式中进度允许暂时下降，执行期间不改计划。停止按钮在当前完整公式结束后生效；第3–5步最长需等待一个八次转动的公式完成。

第5步只完成顶面定向，随后通过第6–7步完成侧色排列，不能把顶面同色等同于整个魔方复原。

## 第6–7步

| 步骤 | 前提 | 完成条件与保护范围 |
| --- | --- | --- |
| 6 · 顶层角块归位 | 前两层完整、白色顶面同色 | 四个顶角位于三色中心对应的槽位且朝向正确；保留前两层和白色顶面，允许顶棱换位 |
| 7 · 顶层棱块归位 | 第6步完成 | 四个顶棱位置及两色朝向正确；保留前两层、白色顶面和全部顶角，最终六面各9张贴纸正确、总计54/54且全部小块位置正确 |

第6步搜索顶角排列，使用U对位、T换位公式及其四个侧向版本、逆公式。第7步搜索顶棱排列，使用Ua三循环、逆公式Ub及四个侧向版本；不单独转U，避免打乱已归位顶角。多个三循环可以处理双交换。两步都规划至完整阶段结束，允许本阶段个别正确块在途中换位。

每段公式末尾检查前置阶段，整套方案末尾检查全部目标，每次实际转动检查与独立模拟一致。第6步停止最多等待当前14次转动的T公式，第7步最多等待当前11次转动的棱循环完成。第7步左侧实时列出六面计数；最终六面检查结果一并写入可导出的操作记录。

## 决策与检查

- `cross-planner.js`：根据真实贴纸状态，用缩减到相关底棱的状态空间进行反向广度搜索。为未完成底棱生成候选方案；每个方案结束后必须保留已有正确底棱，并使正确底棱数量增加。最多4轮有效方案。
- `corner-planner.js`：在底层十字正确的前提下，使用 U 层对位与 `S U^n S'` / `S' U^n S`（S 为 R/B/L/F）角块取出、插入公式。过滤会破坏已有底角的短公式，在单个目标角的24种位置 / 朝向上做按实际转动次数计价的最短路径搜索。每段及整套候选都在完整贴纸状态上模拟检查；每轮至少新增一个正确底角，最多4轮有效方案。
- `layer-planners.js`：第3步用左右插入公式及逆公式归位目标中棱，保护底层及已有正确中棱。第4步使用顶棱定向公式 `F R U R' U' F'`；第5步使用小鱼公式 `R U R' U R U2 R'`。均包含U对位、绕U轴重命名的四个方向和逆公式。使用有限的位置 / 朝向状态搜索完整方案，每个搜索节点携带完整贴纸状态并检查前置阶段；第4–5步搜索到整个阶段完成，允许中间形态的计数不增加。
- `layer-planners.js` 同时提供第6–7步的顶角 / 顶棱排列搜索。按固定顶层槽位记录小块身份，保留完整状态模拟检查；投影后最多24种排列，无需倒放历史。第7步使用独立的六面贴纸和小块位置检查作为最终完成条件。
- `cross-controller.js`：七步共享的执行器。向 Jev 的 `questions.plan` Choice 问题发送当前阶段规则、状态版本、全部54张贴纸、局部目标状态、已完成部分、候选公式及预期效果。只接受候选ID或暂停；每次动画结束核对实际状态，整段方案结束后再规划，各阶段分别核对前置阶段的保护条件。
- `index.html`：Three.js 层转动动画、七阶段切换、四个目标块进度、最终六面检查、非遮挡设置、停止、日志导出及魔方状态本地保存。
- `server.js`：仅绑定本机的 Jev 代理，转发到 `https://api.typesafe.ai/v1/systemone`，处理预检和超时。API Key 保存在当前浏览器的 localStorage，不写入源码或操作日志。

搜索计算完整公式，Jev 负责选择候选方案。Jev 的置信度不用于代替完成检查。网络失败、无效回复、旧状态或实际转动不一致会暂停；不会在失败时伪装成 Jev 继续操作。

`file://` 与本地 HTTP 地址使用不同的浏览器存储；切换地址时可能需要重新保存设置。魔方状态在每次完整转动后保存到 `cubeLab.cube.v1`，刷新恢复状态和转动记录，设置和操作日志继续保留。AI 请求不会在刷新后自动继续；在公式中途刷新可能暂时打破前置阶段，页面会选择实际最早未完成的一步，从该步恢复。3D 引擎仍需联网加载。
